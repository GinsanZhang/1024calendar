# 一页千秋 v2 素材包

本目录以用户确认的两张青绿山水图为统一参考标准，于 2026-10-25 完成素材生成。页面组合后的构图、裁切与连续性在站点开发时验收。

## 接入规则

- 运行时只引用 `.webp`、`.svg`、`.woff2`；同名 `.png` 母版已归档到仓库根 `assets-src/v2/`，本目录不再存放 PNG。
- 所有日期、朝代、事件标题和正文由 HTML 输出，画面素材不含关键文字。
- `hero/mist-*.svg`、`icons/*.svg` 可直接着色或动画；小舟、花枝、卷轴木轴和纪年牌保留透明通道。
- 十四朝代画段配有十三张 `scroll/transition-{from}-{to}.webp` 专用接景图；`transition-neutral.webp` 为备用。
- 二十四节气小景按同一观察点生成，UI 中统一使用圆形裁切，不在图片本身烘焙圆框。
- 本地宋体为 Adobe Source Han Serif CN 2.003R 可变 WOFF2，许可见 `fonts/OFL-Source-Han-Serif.txt`；样式入口为 `fonts/fonts.css`。
- 品牌字标与印章的 SVG 是引用 PNG 的容器，并非转曲矢量。网页 `img` 接入优先使用对应 WebP；不要把外链 PNG 的 SVG 容器当成独立图片文件。
- 画作均为 AI 艺术意象，不作为历史场景实录。生成提示词见上级物料清单。
- `manifest.json` v2 将发布资源与母版分开：`rasters` 登记当前 89 个 WebP 的实际像素、Alpha 范围、字节数与 SHA-256；`archivedSources` 保留 90 个 PNG 母版的历史元数据与 `assets-src/v2/` 归档位置。母版不随 Git 分发，不作为发布必需文件；放大导出不会增加原生细节。素材校验同时检查发布文件存在、完整登记、大小及 SHA-256。

## 目录

- `brand/`：书法字标与朱文印章
- `hero/`：桌面/手机首屏、小舟和双层雾
- `textures/`：绢纹、历纸、旧化叠层
- `calendar/`：纸历结构、翻页、四季枝叶、空白日期
- `scroll/`：十四时代画段、过渡段、左右木轴
- `events/`：十一类入画史事背景
- `seasons/`：圆窗、四季枝叶、二十四节气小景
- `lookback/`：千年回望夜景与纪年牌
- `icons/`：导航、工具、方向、播放和日期印蒙版
