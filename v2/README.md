# 一页千秋 Web 骨架

依据《一页千秋_功能与交互设计规格_v1.0》制作的首板交互网站。当前为无构建依赖的静态前端，可直接本地预览；2026-10-25 已完成正式素材接入，图片加载异常时会自动回退到带编号、素材名称的色块。

## 本地预览

在项目根目录执行：

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8765/v2/`。

## 已覆盖的核心体验

- 青绿山水首屏、三种观看尺度与全局尺度切换。
- 42 格日历、公历 / 农历 / 节气标记、朝代筛选、空日期前后跳转。
- 史事沉浸阅读、前后史事、跨日期阅读与来源说明。
- 14 个时期、92 条年份史事的横向长卷。
- 二十四节气循环，桌面圆环与移动端横向节气带。
- 全局检索、明暗主题、动效暂停、随机穿越与 100–1000 年回望。
- 键盘导航、弹层焦点约束及 `prefers-reduced-motion` 适配。

## 正式素材

素材集中定义在 `js/assets.js`，完整清单见 `物料清单.md`，生成与验收记录见 `素材生成验收记录.md`。

- 品牌字标、印章和本地思源宋体。
- 桌面 / 手机首屏、透明小舟与双层雾。
- 日历纸纹、季节枝叶和空白日山水。
- 14 段朝代画、13 段接景和左右木轴。
- 11 类史事背景、24 张节气小景和圆窗装裱。
- 千年回望夜景与纪年牌。

所有画作均作为艺术意象展示，不作为历史场景实录。

## 验证

```bash
node v2/qa/check-data.cjs
node v2/qa/check-asset-integration.cjs
for f in v2/js/*.js; do node --check "$f"; done
```

数据校验覆盖 131 条公历记录、20 条农历记录、92 条长卷史事、24 节气、5 档回望以及跨年日期；素材校验覆盖 177 个栅格文件及八个页面接入区域。

## UI 还原修复（2026-10-25）

已修复回望按钮遮挡、900px导航/内容断点、节气日期跳转、翻日纸页反馈、长卷嵌套滚动、检索缩略图和手机月历密度，并统一纸面配色与轻导航。
