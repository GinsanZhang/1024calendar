# 素材目录

`assets/` 下的位图、矢量与纹理，按「用途」而非「生成批次」组织。2026-10-24 由扁平目录 `paintings/` `ornaments/` 重组而来。

```
assets/
├── hero/          首屏画境：底图 + 可分离图层
├── dynasties/     14 幅朝代主画（长卷卷首、时代主画）
├── events/        史事题材画，每题材一目录，可放多变体
├── decorative/    装饰性物象（鹤、松、云）
└── data/  vendor/ *.js  *.css   代码与数据，非素材

../archive/        已无取图入口的旧素材，移出 assets，不参与构建
```

## 命名规则

| 类型 | 规则 | 例 |
|---|---|---|
| 整幅画作 | `<名>-768.webp` + `<名>-1536.webp` 两档 | `dynasties/tang-1536.webp` |
| 题材多变体 | `events/<题材>/v<N>-{768,1536}.webp` | `events/battle/v1-1536.webp` |
| 单尺寸图层 | 不加后缀 | `hero/boat.webp` |
| 矢量 | `.svg`，需自带 `width` `height` `viewBox` | `hero/mist-back.svg` |

画作统一 WebP、`cwebp -q 82`，1536 档约 250–400 KiB，768 档约 70–130 KiB。题材图为 1536×960（3:2 裁切后为静帧），朝代图为 1536×1024，另有三幅 1536×768 的宽幅稿（秦、隋、民国）。

## hero/

首屏是一套五层结构，画在同一坐标系（1536×1024）里，靠 `offset-path` 让船沿江心 S 弯行进。

| 文件 | 内容 | 现状 |
|---|---|---|
| `landscape-{768,1536}.webp` | 无船山水底图 | 已有，377 KiB |
| `boat.webp` | 透明小舟（船夫撑篙，朝向右侧） | 已有，640×320，带 alpha |
| `mist-back.svg` | 远景雾带，`mist-drift` 28s | 已有 |
| `mist-front.svg` | 前景雾带，`mist-drift` 36s 反向 | 已有 |
| ~~`wake.svg`~~ | 水纹 | **未建**，见下 |

**水纹不建文件**：`wake` 是三个 `.boat-wake i` 元素用 `border` + `border-radius` + `boat-ripple` 关键帧画出的扩散椭圆，做成静态 SVG 会失去波纹生长动画，且体积反而更大。它属于动效而非素材。

**雾层是矢量**，不是位图。拆成独立 SVG 是为了让雾的形状可以在不动 HTML 的前提下替换；动画挂在元素上，`<img>` 载入 SVG 同样生效。

## dynasties/

14 个键对应长卷的 14 个时期，文件名即 `Gallery` 里的键名：

`xia` `cq` `qin` `han` `sj` `sui` `tang` `wudai` `song` `yuan` `ming` `qing` `minguo` `prc`

**只有 13 幅独立画作。** `song` 用的是一幅通用青绿山水，同时承担三个角色：宋代主画、二十四节气的兜底图、日历卷首的留白底。这是刻意的共用，不是缺失——它本质上是「无所指代的山水」，不属于任何单一朝代。若日后为宋代单独出图，只需替换 `song-*` 一处，节令兜底会跟着变，届时应改为指向 `seasons/jieqi`。

## events/

史事取图以 `data/event-art.js` 为唯一清单，由 `event-art.js` 供主站与 v2 共用。
所有 243 条史事固定保存事件ID。清单写明每条事件的指定文件、适用年代及验收状态；关键词仅为未登记ID的新增事件兜底，已登记条目不会被关键词覆盖。

新增/替换场景：早期/现代会议、1920年代工运、1931–1979现代战争、1964–1967核试验、1976唐山平原震后、2008汶川山城震后、现代外交、1997/1999回归仪式。核试验与航天分开，唐山与汶川分开。回归图使用无可识别天际线的仪式大厅。

- 完整清单：[`docs/事件素材映射清单.md`](../docs/事件素材映射清单.md) 与同名 CSV。
- 重新导出：`node scripts/build-event-art-checklist.cjs`。
- 自动检查：`node scripts/check-event-art.cjs`。
- 提示词及生成方式：`docs/事件素材生成提示词.json`。
- 验收记录：`docs/事件素材验收记录.md`。

素材为艺术意象，不声称复原具体现场；仍使用朝代图的条目明确标为“朝代意象（待专图）”。

## ../archive/（项目根目录）

`palace-*` 与 `frontier-*` 是四画时代的旧方案，朝代表收敛为 14 键后已无取图入口；两个 `.png` 是首屏图层的原始生成稿。全部移出 `assets/`，放在项目根目录的 `archive/`，不参与构建、不计入站点体积。
