# 一页千秋 · 交互规范 v2

> 这套设计的核心不是「三个页面」，而是**一套观察时间的动作**。用户通过动作本身感知尺度，而不是靠文字解释。
> 所有时长取自 `v2/css/tokens.css`，实现与本文一一对应。

---

## 一、四个动词

| 动词 | 视图 | 方向 | 时长 | 用户的心智 |
|---|---|---|---:|---|
| **翻** | 日历 | 纵向 | 280ms | 在触摸时间 |
| **展** | 朝代长卷 | 横向 | 500ms | 在观看历史 |
| **入** | 史事 | 由点到面（墨晕） | 750ms | 在进入画境 |
| **溯** | 千年回望 | 数字与颜色回溯 | 850ms + 600ms | 在改变观察尺度 |

四个动词共用一套节奏：**慢背景、快操作、重转场、轻反馈**。它们不是四套动画，而是同一套语言在不同尺度上的说法。

---

## 二、三个视图的运动语义

| 视图 | 尺度 | 运动 | 不该出现 |
|---|---|---|---|
| 日历 | 以日为单位 | 纵向翻页，有纸厚、有方向、有轻微惯性 | 横向切换、大面积淡入淡出 |
| 朝代长卷 | 以千年为尺度 | 横向展卷，山水随卷轴移动，时间轴同步推移 | 上下滚动、卡片网格 |
| 四时流转 | 以四季为循环 | 环形旋转，节气轮转，色温随季变化 | 线性列表、分页器 |

视图切换本身只做 500ms 的淡入与 8px 位移，**不做左右滑动**——左右滑动属于长卷，不能和「换尺度」混用同一种动作。

## 三、高光一 · 入画（全站最重的 750ms）

### 3.1 时序

| 时间 | 层 | 动作 | 参数 |
|---:|---|---|---|
| 0ms | 墨 | 从点击点扩散到覆盖全屏 | `clip-path: circle(0 → R)`，375ms，`--ease-ink` |
| 120ms | 画 | 山水淡入并轻微收拢 | `opacity 0→1`，`scale 1.06→1`，630ms |
| 300ms | 字 | 题跋整体上浮落位 | `translateY(18px)→0`，450ms |
| 360ms 起 | 字 | 元信息、标题、描述、出处逐行落下 | 每行间隔 26ms，220ms |
| 750ms | — | 焦点移到「返回」 | 键盘可直接 Esc |

墨晕半径取点击点到最远角的距离，保证任何点击位置都能覆盖全屏。

### 3.2 状态机

```
idle ──点击史事──▶ opening(墨) ──▶ reading(画+字)
                       │                 │
                       │            ┌────┴─────┐
                       │       前后一事      Esc / 返回
                       │            │           │
                       │         switching(220ms)  closing(310ms)
                       │            └────▶ reading        │
                       └──────────────────────────────▶ idle
```

- **可中断**：任意时刻按 Esc 立即进入 closing，不等待入画播完。
- **可连续**：reading 状态下点前后一事，只重播 220ms 的内容切换，不重播墨晕。

### 3.3 退出与返回原位

- 收墨：从全屏半径收回点击点，310ms，与展开同一条曲线反向。
- **不销毁原视图**：日历的选中日、长卷的 `scrollLeft`、四时的当前节气全部保留，返回即原位。
- **例外**：若在阅读中按了「跨日」，日历会同步翻到那一天——这是用户主动移动，不是丢失位置。

## 四、高光二 · 翻页（280ms，分两段）

| 段落 | 时长 | 动作 |
|---|---:|---|
| 出页 | 150ms | 纸页绕右缘 `rotateY(-7deg)`、左移 16px、透明度归零 |
| 换内容 | 0ms | 立即重绘 42 格 |
| 入页 | 130ms | 新页从 `rotateY(7deg)` 回正 |

- **换月**用这套翻页；**换日**只用 220ms 的数字翻动 + 内容重排，不翻页。
- 理由：日常浏览是一天一天看的，每天翻一次纸会累；只有跨越月份才值得一个仪式。
- `transform-origin` 随方向翻转：向后翻页锚在右缘，向前翻页锚在左缘。
- 纸堆：日历纸页右侧常驻两条纸边，暗示「后面还有」。

## 五、高光三 · 展卷（横向）

| 元素 | 行为 | 参数 |
|---|---|---|
| 面板 | 每朝一屏，`scroll-snap: x proximity` | 100vw / 100svh |
| 山水 | 随滚动做 38px 反相视差，整条只朝一个方向移动 | `translate3d(±38px)` |
| 换色 | 进入新朝代时 `--era` 系列插值 | 500ms |
| 时间轴 | 刻度按 `index / (n-1)` 定位，当前刻度拉高着色 | 500ms |
| 题跋 | 朝代名、起止年、简介、前 4 条纪事 | 纸质卡，92% 不透明 + 模糊 |

时间轴右上角常驻「回望千年」，是长卷唯一的跨尺度入口。

## 六、高光四 · 溯时（回望）

1. 打开深色面板：纪年从当前年份开始，选 100 / 300 / 500 / 800 / 1000 年。
2. **纪年回溯**：数字从 2026 递减到目标年，862ms，指数缓出。
3. **同步换色**：每一帧按当年所属朝代刷新 `--era`，颜色随年份流动，而不是最后跳一下。
4. **落位**：显示目标朝代与起止年，朱砂细线横扫 620ms。
5. **展开**：关闭面板，长卷直接定位到该朝代（不做长距离平滑滚动），提示「已回望 N 年，落在 X」。

用户感受到的是**一次穿越**，不是一次筛选。

## 七、前后一事的排序规则（必须显式）

「前一事 / 后一事」很容易制造虚假的连续性。规则定死，并在界面上写明：

| 场景 | 顺序 | 按钮标签 |
|---|---|---|
| 同一天内 | 公历 → 农历 → 节气；组内按年份升序 | `同一日 · 上一则 / 下一则` |
| 跨日 | 取最近一个有记载的日期，落在其首条或末条 | `跨日 · 10 月 25 日` |
| 长卷内 | 该朝事件的年序；到头则跨到相邻朝代 | `同一时期 · 下一则` / `跨朝代 · 后一卷` |
| 界面上常驻 | 入画底部写明「同日按 公历 → 农历 → 节气 排列，跨日取最近有记载的一天」 | — |

同时，画卷必须标注**「意象画 · 山河新章　据事件性质取图，非史料复原」**：画是氛围，不是史料。

## 八、空白日引导

365 天里只有 125 天有确切记载，覆盖率 34%。空白不能靠编补，只能靠引导：

1. 日历格里留白，不放假标记。
2. 当日面板显示「此日史册留白」+ 一句解释，不写虚构文案。
3. 给出「上一段往事 / 下一段往事」两个入口，向前后各找 60 天内最近的记载，显示日期 + 首条标题。
4. 点击后翻到该日，并用 toast 说明「已翻到 10 月 25 日」，让用户明白自己移动了多远。

## 九、键盘与焦点

| 键 | 视图内 | 全局 |
|---|---|---|
| ← → | 日历翻日 / 长卷换朝 / 四时换节气 | — |
| ↑ ↓ | 日历翻周 | — |
| 1 / 2 / 3 | — | 切到 日 / 千年 / 四季 |
| `/` 或 `⌘K` | — | 打开检索 |
| Esc | 关闭当前层 | 逐层退出（检索 > 回望 > 入画） |
| Enter | 检索中打开选中项 | — |

弹层打开时锁滚动，关闭后恢复到原位置。

## 十一、当前实现的已知边界

1. **长卷 14 幅画的绘法不统一**：部分是绢本设色，部分是写实渲染（如夏商周的青铜鼎、唐的长安城）。这是 v1 留下的素材问题，交互层无法弥补；若要统一气质，需要重出这批图。
2. **四时视图仍无节气小景**：中央环窗是文本 + 色温，不是《十二月令图》式的画。补 12–24 张节气画后，这一页的表现力才会与长卷齐平。
3. **回望只能落在朝代粒度**：数据里只有朝代区间，没有逐年事件，因此回望到某一年只展示该朝代，不展示当年。
