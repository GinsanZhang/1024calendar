# 字体优化 · 2026-10-23

保留山水画卷的主视觉和宋体大标题，通过更清楚的辅助信息与正文，改善从欢迎页进入历史阅读的连续性。

## 字体角色
- 宋体：品牌、引言、大标题、朝代名和史事标题。
- 黑体：正文、按钮、纪年、农历和出处；数字使用 tabular-nums，便于横向比较。
- 本地字体回退补充 Noto Serif CJK SC 与 SimSun，保留离线能力。本轮在 macOS Chromium 验证，未对 Windows/Android 实机字体作保证。

## 阅读层级
- 史事与长卷正文：桌面 15px，手机 14px，行高 1.85–1.95。
- 辅助信息：11–12px；农历、回望农历、出处不再使用 8–9.5px。
- 操作文字：12–13px，欢迎页主按钮为 15–16px。
- 欢迎页说明字距 .02em，主按钮 .04em，引言 .08em；大标题大小与两行构图保留。

## 排版细节
- 回望农历在桌面可换行；手机延续隐藏该辅助行，避免五格信息过密。
- 长出处可换行，朝代导航按内容撑开并允许横向滚动。
- 日历卷首说明按完整短句换行，避免「处。」孤立成行；史事和长卷正文使用 text-wrap:pretty 渐进增强。
- 搜索框字号 16px；页脚和详情中的说明文字同步放大。
- 更新 style/refinement/welcome 样式资源版本，保留现有船、仙鹤和时期素材实现。

## 验证
- 320、390、768、1024、1440px 宽度检查无页面横向溢出；目标小字、按钮和出处无裁切。
- 桌面欢迎页、日历、长卷及手机欢迎页、日历、长卷、详情截图检查。
- 逐项检查十四个朝代按钮的内容边界，修复「夏商周」长纪年空间不足。
- 现有 scripts/check-experience.js 六项回归通过：筛选重置、模态焦点、背景隔离、图片回退、日历键盘、视图与朝代键盘。
