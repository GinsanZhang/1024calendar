## 2. 作品简介 · 详细版（约 600 字）

```
「一页千秋」是一个能沿日期和朝代双向往回走的中国历史日历。翻一页，穿一回千年。

打开它，先是一幅青绿山水：云雾在峰间流动，一叶小舟自近而远驶向江心。进入之后是今天的日历——公历日期旁边是农历与节气。右侧是这一天的中国史事，每条都标着朝代、纪年和出处。若这天正史未载确切日期，它不会编，只会留白，并告诉你：这条日期落在北宋、南宋、明、清、民国五个朝代里分别是什么样子。

点一下任意一条史事，画卷就从你手指按下的地方铺开：先是一层该朝代颜色的墨晕扩散整屏，接着一幅那个时代的主画落在眼前——夏商的青铜、春秋的竹简与剑、唐的城楼与浮屠、明的宝船、清的门与石；文字随画卷落下，年份化作水印沉在角落。关上画卷，整个页面的色调已经跟着那个朝代变了。

第二种走法在「朝代长卷」。从共和国的此刻一路退到三千年前的青铜器上，十四个时期排成一条时间轴，每个时期有自己的主画与颜色，点开即换画换色，展开它的大事记。

第三种走法是「四时流转」：二十四节气沿一支年盘排开，指针停在今天的节气上，圆盘里是当令的画境；可以拖动日期看年内任一时刻，也可以播放一整年。全站前景还会按真实交节时间浮出当令物象——雨水、雷雨、霜花、雪晶，二十四组各不相同。

公历与农历是两套历法，古代史事多按农历记载，所以我们不把它硬塞进公历格子，而是分层标注、各归其位。全站离线可用，快捷键 T 回今天、R 随机穿越、/ 搜索。
```
