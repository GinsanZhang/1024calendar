# 时代素材

## 目标
十四时期各有独立主画。长卷、事件画卷、日历卷首与页面点景沿同一时期切换。欢迎页为通用山水，不随日历时期改变。

## 实现约定
- 主画使用内置 imagegen；每幅单独生成，WebP 1536px/768px 本地资源。
- 宋沿用现有 landscape，共和国沿用 river；其余十二时期补画，所有十四个时期主图路径唯一。
- 边角沿用可编辑 SVG 的时代轮廓，统一取 ART.scene，不再让流云、松石和双鹤出现在所有时期。
- 所有图按需加载，错误保留 SVG 兜底；不预加载整个图库。
