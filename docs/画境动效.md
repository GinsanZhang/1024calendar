# 活的山水欢迎页

2026-10-23。背景按水面、船、倒影/涟漪、云雾分层。沿用现有仙鹤图层，加入轻缓滑翔。标题和操作区域保持稳定。

## 行为

- 小舟沿江面单向缓行，轻微起伏；水纹向船尾扩散，带淡淡倒影。
- 两层薄雾以不同速度移动。原有仙鹤做小幅滑翔。
- 航程按屏幕可见江面计算；手机调整取景、船的高度，避开日期牌。
- 右上角可暂停/继续，选择在本次会话内保留。进入日历、切到后台时暂停。
- 系统减少动态效果开启时保留静态小舟，停止动画；设置在页面打开后变化也会响应。
- CSS 动画承担运动；JS 只在尺寸、显示状态或用户操作变化时更新，无常驻逐帧脚本循环。
- 新底图加载失败时恢复原山水及原静态小舟，避免叠出两艘船。
