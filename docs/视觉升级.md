# 视觉升级

## 设计方向
以中国绘画长卷与博物馆装裱为主线，插画承担沉浸感，日历和文字保持安静可读。

- 色彩：绢白 #F5F1E7、墨 #262923、青绿 #557969、石青 #687F90、旧金 #A07C43、朱砂 #A64032。
- 字体：系统宋体用于标题，系统黑体用于正文，数字保留等宽和表格对齐。
- 布局：卷首短幅山水引入；左日历右档案；朝代页以大幅画作与短述组织；画卷以图文装裱呈现。
- 节制：取消大面积脏斑和画作上的密集粒子，让真实笔触、留白和轻微翻卷过渡成为重点。
- 性能：WebP 本地化；大图按需、明确尺寸；SVG 兜底；支持离线和减弱动态效果。

用户明确希望生成精致素材，本轮允许本地位图资产，替代旧文档的“零位图”限制；其余数据真实性、出处和本地资源原则继续有效。
