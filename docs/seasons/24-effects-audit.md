# 二十四节气物象逐项检查 · 2026-10-23

## 画法

全站前景与四时仪内部的物象使用 Canvas 2D：Path2D、贝塞尔曲线、描边、透明叠色与渐变。山水底景使用 SVG，内部飘落粒子使用 CSS 动画，雪晶由同源路径同时生成 Canvas 路径和 SVG 蒙版。没有外部天气服务或物象图片依赖。

本次麦穗使用细化矢量几何生成 3× 离屏缓存，再随茎秆与穗头的不同摆幅合成。缓存最多 20 张（青麦/熟麦 × 明/暗 × 5 种形态），避免逐帧重画数百片颖壳。

## 独立检查结果

逐个选择24个节气，截取实际全站画布的局部原尺寸画面与全景缩图；检查轮廓、连接、细节、层次与节气差异。以下“保留”表示检查后沿用该画法，不表示每一项都重新绘制。

## 验证

- 桌面 1440×960 浅色及手机 390×844 暗色的24节气回归通过：实际像素、全站/年轮同步、麦穗运动、暂停稳定、场景交接暂停、大小雪差异、雨后流萤、跨页面联动、无天气选择器。
- 手机无横向溢出；麦穗茎叶与近景穗头在正常尺寸可辨认，中部远景保持低对比。
- 减少动态效果：清明、芒种、大雪均停止全站画布和交接动画，并隐藏画境粒子。
- JavaScript 语法、git diff 空白检查通过。
