# 四时 · 动态节气系统

## 目标
在一页千秋现有项目新增四时视图，将一天、一个节气和一年三个时间尺度可视化，并与日历选中日期互通。本轮只开发和本地预览。

## 设计
延续纸本与宋体，圆形四时仪为主视觉。颜色：纸 #F4EFE6、墨 #344A42、春 #718968、夏 #337B74、秋 #AC713C、冬 #728A9B。圆内使用可随季节变色的山水和粒子；圆外呈现二十四节气和太阳黄经位置。右侧为节气释义、交节时间、下一节气倒计时。下方提供日内刻度、年度日期拖动、全年播放和完整节气索引。手机上下排列。

## 实施计划
1. 接入第三视图、欢迎页入口与日历状态联动。
2. 实现精确交节状态、时间刻度、年轮、四季景观和播放控制。
3. 验证交节前后、跨年、闰年、键盘、手机、暗色和减少动态效果。

## 数据与边界
- 使用项目现有 lunar.js 历算结果，统一按北京时间处理，不用固定日期推算节气。
- 2026 香港天文台年历用于交节时间抽查。历算结果与年历可能有秒级差异，界面约至分钟。
- 日内圆弧为北京时间的24小时刻度，不宣称为实际日出日落。
- 四季物象是艺术示意，不是实时天气或当地气候。

## 说明
此系统的时间刻度、交节状态与倒计时是真实历算；画境是艺术化四季示意，不是当地实时天气。日内色带代表民用钟时，不用于计算日出日落。

- 自动联动检查通过：无选择器，大小雪密度差异、小雨/雷雨密度差异、闪电路径、云影与霜花缓存均生效。

## 雨幕与雷电重绘
- 根据雨/雷效果不足的反馈，将稀疏、方向不一致的雨线替换为独立的 rain-atmosphere.js：三层雨滴有不同速度、长度、宽度与透明度，雨线方向由实际速度投影决定，随风缓慢变化。
- 雨滴真实落地后生成短促溅水和双层扩散水纹；四时仪内部使用同一批雨滴、落点和时钟，并移除旧 CSS 雨线。
- 闪电使用细分主通道、四条分叉及次级支线，分层绘制晕光、外缘和亮芯，加入局部云光及余辉。低频单次放电，保持全站暂停、后台与减少动态效果支持。
- 新增 check-rain-atmosphere.js，验证三层雨幕、实际运动与落点、主场景/年轮同步、分叉放电、暂停稳定、换节气清理以及大暑雨歇流萤。
- 桌面浅色及390手机暗色专项检查通过，24节气回归通过；记录图像为 rain-thunder-light.png 与 rain-thunder-mobile-dark.png。截图复制真实放电帧用于静态审视，没有手工绘制额外雷电。

- 全站缓存按矩形窗边生成；四时仪独立按圆弧生成，保留透明中心。小寒保持较细的针状晶簇，与霜降晶面不同。
