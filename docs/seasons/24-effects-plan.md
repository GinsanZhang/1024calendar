# 二十四节气独立特效设计清单

用户要求：不用天气选择器，效果自动跟随节气；尽量每个节气都有独立特效。

已按用户确认的清单实现二十四组独立物象。各节气共用云雨、雪晶与冰霜基础，但主体几何、数量、色彩、运动节奏和时间阶段分别配置；全站与四时年轮内部同步。

| 季节 | 节气 | 主效果与辨识点 |
| --- | --- | --- |
| 春 | 立春 | 残雪消融：边缘薄冰慢慢退去，零星嫩芽与花瓣出现。 |
| 春 | 雨水 | 春雨润物：细而疏的小雨，落地荡开轻微涟漪。 |
| 春 | 惊蛰 | 春雷初动：云影聚拢、斜雨，偶尔一束细闪电划过天边。 |
| 春 | 春分 | 燕归花飞：成双燕影掠过，花瓣匀速轻旋。 |
| 春 | 清明 | 柳烟薄雾：青灰薄雾缓缓游移，少量柳絮飘散。 |
| 春 | 谷雨 | 雨生百谷：绵密春雨，水纹连绵，伴随轻轻舒展的绿意。 |
| 夏 | 立夏 | 绿荫流光：柔和叶影掠过纸面，光斑缓慢移动。 |
| 夏 | 小满 | 麦穗将盈：底边少量麦穗随风起伏，金绿相间。 |
| 夏 | 芒种 | 芒穗随风：纤细麦芒与草籽顺风漂移，田野波纹轻起。 |
| 夏 | 夏至 | 日影流转：暖色日晕缓慢移动，光影舒展开。 |
| 夏 | 小暑 | 荷风微雨：浅浅水纹、轻雨与少量荷瓣，节奏舒缓。 |
| 夏 | 大暑 | 骤雨流萤：云层压低，阵雨增强，雨歇后浮现微弱萤光。 |
| 秋 | 立秋 | 一叶知秋：零星青黄叶片翻转落下，数量较少。 |
| 秋 | 处暑 | 浮云散暑：云影逐渐变薄，暖色轻雾慢慢消散。 |
| 秋 | 白露 | 叶尖凝露：边缘露珠逐渐聚起，呈现细小水光。 |
| 秋 | 秋分 | 金叶旋舞：金黄银杏与枫叶交错，缓缓回旋。 |
| 秋 | 寒露 | 冷雾凝珠：冷蓝薄雾、清透露珠，叶片速度放缓。 |
| 秋 | 霜降 | 霜花蔓延：窗边般的蕨状冰晶从四角渐渐结起。 |
| 冬 | 立冬 | 寒风收叶：最后几片枯叶被风斜送，边缘透出寒意。 |
| 冬 | 小雪 | 疏雪轻扬：小而疏的雪晶慢慢飘落，远景细粒为主。 |
| 冬 | 大雪 | 密雪纷飞：雪量明显增加，近景大雪晶与远景细雪分层。 |
| 冬 | 冬至 | 雪夜微光：深蓝夜色、柔和月晕与稀薄细雪。 |
| 冬 | 小寒 | 冰窗细纹：细密针状霜纹，搭配缓慢飘下的小冰晶。 |
| 冬 | 大寒 | 冰霜风雪：更厚的冰霜纹理与斜向风雪，层次最丰富。 |

共同原则：自动跟随当前浏览日期对应的节气；欢迎页使用此刻节气。每个节气突出一个主效果，变化时柔和过渡，保留全站暂停和系统减少动态效果支持。所有景象属于物候艺术意象，不代表当地实时天气。

## 验证与实现

- 实现：assets/phenology-art.js 定义24组配置及物象绘制，assets/seasonal-fx.js 负责时间、公共气象、生命周期与跨视图状态。
- 新增 scripts/check-24-phenology.js：逐节气验证实际像素绘制、局部画境、独立身份、大小雪、针状/蕨状霜纹、麦芒运动、共享暂停、雨后流萤以及日历与朝代联动。
- 已完成桌面明暗、手机、减少动态效果及既有节气/日历/搜索/画卷回归。
- 大暑采用28秒的气象循环；雨景与流萤平滑交接。立春冰层逐渐消融；霜降冰晶逐渐凝结；处暑云影与暑气逐渐淡去。
- 场景切换保留上一帧并用700毫秒淡入淡出；暂停、后台与减少动态时停止绘制及过渡。
