## 一、作品简介（投稿表单用，详细版）

「一页千秋」是一个能沿日期和朝代双向往回走的中国历史日历。翻一页，穿一回千年。

打开它，你会看到今天的日历——公历日期旁边是农历与节气。右侧是这一天的中国史事，每条都标着朝代、纪年和出处。若这天正史未载确切日期，它不会编，只会留白，并告诉你：这条日期落在北宋、南宋、明、清、民国五个朝代里分别是什么样子。

点一下任意一条史事，画卷就从你手指按下的地方铺开：先是一层该朝代颜色的墨晕扩散整屏，接着一幅那个时代的主画落在眼前——夏商的青铜、春秋的竹简与剑、唐的城楼与浮屠、明的宝船、清的门与石；文字随画卷落下，年份化作水印沉在角落。关上画卷，整个页面的色调已经跟着那个朝代变了。

第二种走法在「朝代长卷」。从共和国的此刻一路退到三千年前的青铜器上，十四个时期排成一条时间轴，点开任意一个，页面随即换成那个朝代的颜色，展开它的大事记。

公历与农历是两套历法，古代史事多按农历记载，所以我们不把它硬塞进公历格子，而是分层标注、各归其位。全站离线可用，快捷键 T 回今天、R 随机穿越、`/` 搜索。

## 二、功能清单

**欢迎页 · 山水入卷**
- 首屏是一幅青绿山水：云雾缓缓流动，一叶小舟自近而远驶向江心，船后拖出涟漪
- 双鹤自山间掠过，松石、流云为透明底装饰层，随视差轻移
- 可暂停画境（右上角按钮），系统开启「减弱动态效果」时默认静止

**日历视图**
- 公历 + 农历双历对照，格内小字显示农历日期，遇节气自动换成节气名
- 朱红圆点 = 有确切到日的史事；赭色圆点 = 有农历纪事
- 当日档案：千年回望 + 按历史时期筛选 + 公历纪事 / 农历纪事分层展示
- 「本月另有 N 天有记载」——顺着这一月往下翻

**千年回望（核心交互）**
- 同一条日期，往前推 100 / 300 / 500 / 800 / 1000 年，分别落在哪个朝代、农历几月几日、干支何年
- 点任一格，直接跳到对应朝代的长卷

**朝代长卷**
- 14 个时期：夏商周 → 春秋战国 → 秦 → 汉 → 魏晋南北朝 → 隋 → 唐 → 五代十国 → 宋 → 元 → 明 → 清 → 民国 → 共和国
- 每个时期有定位短述与 4—8 条大事记，均注出处
- 每个时期有独立主画（14 幅），点开即换画换色，不再是几个场景反复套用

**四时流转（第三视图）**
- 一支全年节气仪：二十四节气沿圆盘排开，指针随实时时刻走到今天所在的节气
- 圆盘内是当令画境（春夏秋冬四时山色），随节气切换
- 可拖动日期看年内任一时刻、可播放全年，也可点任意节气进入那一天
- 全站前景层按浏览日期与真实交节时间浮出当令物象：雨水、雷雨、霜花、雪晶，共 24 组独立物象，可一键暂停

**沉浸层（点击即穿越）**
- 朝代配色系统：十四个时期各有一套色，切到哪个朝代，全站主色、纸色、顶部色带、背景光晕一起过渡过去
- 墨晕转场：点开史事时，一团该朝代颜色的墨从点击处扩散铺满全屏再退去
- 十四幅时代主画：夏商周的青铜、春秋战国的竹简与剑、秦的长城烽燧、汉的阙与五铢、魏晋的竹林佛光、隋的运河拱桥、唐的城楼浮屠、五代的断壁残旗、宋的山水孤舟、元的草原弓马、明的宝船怒涛、清的门与太湖石、民国的洋楼路灯、共和国的天际线；另有四时节令画境与欢迎页山水。均为双分辨率 webp，加载前先以内联 SVG 线描占位，图未到时也不会空白
- 粒子层：Canvas 实时粒子，平时是极淡的浮尘，点日期从格子里迸出该朝代的粒子（先秦方、唐花瓣、宋墨点、元草叶），画卷打开时从图区飘散
- 纸感：整页纸纹不是图片，是 `feTurbulence` 程序化噪声叠出来的——纸浆厚薄不均、细颗粒、边缘旧化暗角，三层叠加。随明暗主题与朝代色自动适配

**其他**
- 关键词搜索：人物、事件、朝代、公元年份、纪年、出处均可；上下键选择结果，Enter 打开；除夕可跳转到当年实际日期
- 随机穿越：一键跳到某个有记载的日子
- 键盘操作：`↑↓←→` 移动日期，`T` 今天，`R` 随机，`/` 搜索，`Esc` 关闭
- 明暗双主题，移动端适配，`prefers-reduced-motion` 尊重系统设置

## 三、三个设计决定

**1. 不把古代史事塞进公历格子**

古代史书按农历纪日（正月初五、三月廿九）。直接映射到公历就是伪造日期。所以做成分层：公历纪事按公历归位，农历纪事按农历归位，各自带标签，读的人一眼看得见这是哪套历法。

**2. 找不到确切日期就留白**

131 条公历纪事只覆盖 125 天，剩下的日子是空的。没有去凑数。空态里写的是：「古史纪事，多详其年而略其日。此处空白，非无史，乃无确切之日。」同时给出本月其它有记载的日子，不至于走进死胡同。

**3. 每条都给得出出处**

正史事件注《史记》《汉书》《资治通鉴》《明史》等具体篇目；近现代事件注《中国共产党历史》《中华民国史》《中国人民解放军战史》等。页脚写明：出处标注至史书与文献一级，部分年份为学界通行说法，精确卷次请核原书。

## 四、使用说明

1. **看今天** — 打开即是当日。左侧月历，右侧这一天的记载。
2. **换一天** — 点日历上任意格子；或按 `↑↓←→`；或点「穿越」随机跳。
3. **穿越朝代** — 点「千年回望」里任一小格，直接跳到那个朝代；也可切到「朝代长卷」，从共和国一路往回点。
4. **找东西** — 按 `/` 或点搜索，输入「贞观」「郑和」「1911」都可以。

## 五、数据与实现

| 项 | 说明 |
|---|---|
| 内容量 | 267 条：公历纪事 131、农历纪事 20、二十四节气 24、朝代长卷 92（14 个时期） |
| 农历换算 | lunar-javascript（MIT），本地打包，覆盖公历 1—9999 年 |
| 技术栈 | 原生 HTML / CSS / JavaScript，零依赖、零构建、无后端 |
| 视觉 | 14 幅时代主画 + 四时节令画境（webp，双分辨率）；15 幅内联 SVG 线描场景；Canvas 粒子与 24 组节气物象引擎；`feTurbulence` 程序化纸纹；`@property` 驱动的 CSS 变量过渡 |
| 体积 | 站点资源约 12.2 MB（其中 37 张 webp 主画与透明底装饰约 11 MB，农历库约 300 KB），全部同源、无外部请求，可离线 |
| 兼容 | Chrome / Safari / Edge 现代版本；移动端单列布局 |

**为什么不用在线接口**：评审时要能打开就能用。第三方「历史上的今天」接口在国内常常不可达，一旦失败整页就空了。所有内容本地化，断网也能翻。

**关于画作**：页面里的时代主画与节令画境是 AI 生成的意象图，不是史料复原，也不冒充古画——画卷内已标明「画作由 AI 生成，为艺术意象，非事件实录」。它们的作用是让人一眼认出「这是哪个时代的气象」，考据交给文字与出处。装饰图形（流云、松石、双鹤）、纸纹与粒子则是程序化生成的：纸纹是 `feTurbulence` 噪声算出来的，场景线描是内联 SVG，无一张外部素材，可离线显示、任意分辨率不糊、还能跟着朝代换色。

**纸纹为什么要算而不是画**：曾经试过用纹理图片，两个问题——位图只能平铺，缩放后颗粒会糊；而且颜色固定，深色模式得另出一套。`feTurbulence` 是程序化噪声：无限平铺无缝（频率乘尺寸取整数即可无缝拼接）、任意分辨率不糊、体积只有几百字节、还能按明暗主题换混合模式。三层叠加分别是纸浆的厚薄不均、细颗粒、以及四周的旧化暗角。

**动效的可关闭性**：粒子与转场都检测 `prefers-reduced-motion`，系统开了「减弱动态效果」就自动降级为直接切换；纸纹在 `prefers-reduced-transparency` 下整层隐藏；移动端自动把纹理从五层减到两层，避免多层混合拖累滚动。
